## Заметки
- Каждый шаг укладывается в мс: показать индикатор времени ответа (p95 6.4 мс; под нагрузкой 8 потоков p95 20 мс).
- Подготовка: открыть UI заранее, прогреть запросом, держать вкладку с `docs/bpmn/process.png`.
- Для 5-минутного этапа показать шаги 1, 3, 5 (около 2 мин), остальное в слайдах.
